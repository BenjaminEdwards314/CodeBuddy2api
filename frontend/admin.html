API 使用示例

curl 示例:

curl -X POST "http://127.0.0.1:8001/codebuddy/v1/chat/completions" \ -H "Authorization: Bearer YOUR_PASSWORD" \ -H "Content-Type: application/json" \ -d '{ "model": "deepseek-v3", "messages": [ {"role": "user", "content": "Hello!"} ] }'

Python 示例:

import openai client = openai.OpenAI( api_key="YOUR_PASSWORD", base_url="http://127.0.0.1:8001/codebuddy/v1" ) response = client.chat.completions.create( model="deepseek-v3", messages=[ {"role": "user", "content": "Hello!"} ] ) print(response.choices[0].message.content)
